# Gitに含める情報

追跡対象は、汎用ソース・架空テスト・設定例・設計と手順です。個人名、ユーザー名、メール、端末の絶対パス、本番URL、クラウドのアカウント/DB ID、残高・保存件数・接続履歴、実投稿・メモ、認証情報は含めません。

実環境の設定と運用記録はGit管理外の .cache/、実データはdata/等の除外先に置きます。秘密を含むファイルは所有者だけが読める権限にします。Workers SecretsとOAuth保管領域の境界を保ち、MCPへ管理権限を渡しません。

commit前に `git diff --cached` と追跡ファイルを確認してください。`.gitignore` は既に追跡されたファイルには効きません。個別記録を含む文書を改訂する場合、原文を管理外に保全してから汎用の説明へ置き換えます。別作業の未コミット変更を一緒に追加しないでください。

通常の修正commitは過去のcommit内容を消しません。履歴にある情報の削除は、バックアップ、共同作業者、既存clone、リモートの参照を確認したうえで別の履歴整理として扱います。認証情報が流出した場合は履歴削除だけに頼らず失効・再発行してください。
