# 技術判断

個人の契約・残高・データ内容・会話履歴を含めず、再利用できる判断だけを記録します。

## 公式通知を主な更新経路にする

X Activity APIの like.create / outboundを使い、定期的な全いいね再取得を避ける。署名とactorを検証し、永続保存後にACKする。UUIDで再送を排除し、通知本文があれば投稿を再取得しない。著者名は配信済み情報だけを使い、プロフィール参照を追加しない。

## 公開入口と保存・取得権限を分ける

公開gatewayは認証DB、非公開coreは投稿DB・暗号化OAuth・X秘密を持つ。受信口にD1や閲覧APIを置かない。プレビューはDB・秘密・内部bindingなしの非公開Workerへ隔離する。受信とcoreの両方で署名、gatewayとcoreの両方で読み取り権限を確認する。

## 有限期限と停止を費用制御の前提にする

購読を短いleaseとし、残高・予算が確認できた場合だけ更新する。台帳は予約額であり実請求額とは区別する。通知が配信された後に拒否しても発生済み料金は消えない。無料枠だけでの永続運用を保証しない。自動チャージ・追加購入・有料プランへの変更を行わない。

## 本文と本人編集を分ける

本文は期限付きsource、メモ・タグ・既読はuserとして分離する。更新・期限切れ・分類変更で編集を初期化しない。既存WebではIndexedDBを維持し、共通同期への接続は別に扱う。移行目的のX再取得を避け、元データを残す。

## MCPは保存済みストックの読み取りに限定する

X Likes Readerをstdioで動かし、4つの限定POST経路だけを使う。Web Cookie、X秘密、Cloudflare管理権限をクライアントへ渡さない。期限付き・クライアント別read tokenと件数/本文上限を設け、X追加取得・編集・購読変更を行わない。投稿内の指示を信頼せず、いいねを採用・賛同とみなさない。

## 2026-10-17: 個別運用情報をGitから分ける

追跡対象は汎用コード・架空fixture・設計・手順とする。接続先やクラウドIDをソースから外し、Git管理外のdeployment.json/認証ファイルへ置く。秘密の発行や既存接続の失効は伴わない。MCPは所有者が設定したHTTPS originだけへ接続し、ツール引数で接続先を指定できない。

クレジット期限は個別の運用状態control.freeStopAtとして扱う。期限未設定を無期限と解釈せず、購読作成と有料参照を停止する。設定例は過去期限・同期無効から始める。元の運用文書とローカル作業はGit管理外に原文を保全する。

型/OpenAPI、API 57件、MCP 4件、送信対象Web 105件とgateway/coreのdry-runを検証。期限が空・不正・経過済みの場合に通信前に止まることを架空データで確認した。通常のpushで過去履歴は書き換えず、履歴削除は別の作業として扱う。

## 2026-10-17: 公開説明とデモを個別運用から独立させる

READMEは英語を入口に日本語版を用意し、現状の機能と制限を両方で説明する。スクリーンショットは実UIと内蔵の架空サンプルから撮影し、既存ブラウザー・実アカウント・個人DBを使わない。demoは環境ファイルをロードせず、X・外部取得・書き込みAPIを持たない。撮影時は外部通信を遮断し、出所・サイズのmanifestを保存する。

ソース公開と個人用Web公開を分ける。過去の個別記録があるリポジトリはそのまま公開せず、確認済み最新版を履歴なしで切り出す。公開設定・既存履歴の強制更新・ライセンス付与はこの文書整備に含めない。未公開の棚UIは既存作業として保全し、画像にも使わない。

個人設定のない切り出しソースで依存導入、型/OpenAPI、167テスト、撮影コマンドを検証。架空のメモを含む3画面を目視し、外部通信と画像metadataを確認した。READMEの英日切り替えとローカル参照先を検査し、公開設定を変えずにレビューできるソースZIPを用意する。

## 2026-10-17: 公開版を新しいGit履歴で開始する

公開用スナップショットから独立したGitリポジトリを作り、親commitなしの初回commitをmainへ登録する。旧リポジトリのbranch/tag/object、PR、運用履歴を継承しない。今後のソース管理は公開版を正本とし、旧非公開版は保管用に残す。

Mac上の配置を維持してGit管理だけを切り替える。旧Git管理情報と未コミット作業をローカルでバックアップし、個人データ・秘密・接続設定はGit管理外のまま保持する。公開前に全追跡ファイルと初回commitの親・参照先・作成者情報を検査する。ライセンス付与と本番デプロイは伴わない。
