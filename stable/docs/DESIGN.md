# margin 設計（要点）

## 製品の軸
- **対象:** あなた自身が X でいいねした投稿だけを扱います。おすすめ・フォロー・他人のいいね・RSS は対象外です。
- **読み心地:** X の公式クライアントに近い構造にしました。左ナビ・タイムライン・右サイド、投稿詳細・スレッド・引用・メディア閲覧です。ただし X の製品ではなく、X のロゴや製品名は使いません。
- **流れ:**
  - 未読 → 既読（詳細を開くと既読）
  - あとで（日時つき。時間が来ると未読の先頭に「あとでから戻りました」）
  - 残す、または済み（X のいいねは外さない。いつでも戻せる）
- **補助:**
  - まとまり：ジャンル（自動・あなたが修正可）、同じ記事、関連
  - 投稿詳細の下：「リンク先の記事」「整理」「つながり」「この記録について」の順で、段階的に出します
- **モバイル最優先:**
  - 下タブ（いいね・あとで・残す・まとまり）。詳細では、親指の位置に「あとで・済み・残す」を置きます
  - 詳細は履歴に積むので、端末の戻る操作でもスクロール位置と絞り込みが戻ります
  - 誤操作しやすいスワイプは使いません。入力中は下の固定ボタンを隠します
  - ボタンは 40×44 以上。320px でも横にはみ出しません

## データ
- **保存先:** IndexedDB「margin-v1」の items / kv / batches / articles / media です。
- **1 件の形:**
  - `id`：`x:<投稿ID>`。重複はこの ID で 1 件にまとめ、`meta.merged` に回数を残します
  - `src`：取得元の値。再取得・取り込みで更新してよいのはここだけです
  - `user`：あなたの編集。状態・既読・あとで・タグ・メモ・ジャンル・貼ったリンクで、取得では上書きしません
  - `meta`：入手経路（manual / sample / mock / import）、いいねした時刻、最後に確認した時刻、`missing`
  - `rev`：書き込みのたびに +1
- **複数タブ:**
  - 「画面が見ていた値」と保存済みの値を比べ、同じ項目が先に変わっていれば競合として知らせます
  - メモは入力を残したまま、上書きするか向こうを使うかを選べます
  - 変更は BroadcastChannel で他のタブへ届けます
- **保存の失敗:** バナーで知らせ、その変更は反映しません。
- **自動では消しません:**
  - 取得元で見つからないいいねは印を付けるだけです
  - 消すのは「架空データを取り除く」と「取り込みの取り消し」を明示的に選んだときだけです

## ジャンル・つながり（手元で計算）
- **ジャンル:** 辞書の言葉が何回出るかで決めます（読み込み済みの記事本文も手がかりに使います）。根拠の言葉を表示します。
- **つながりの種類（混ぜずに区別して表示）:**
  - 同じ投稿：統合済み
  - スレッド：返信先
  - 同じ記事：URL を正規化して比べる。転送後の URL も使う
  - 関連：共通の言葉 2 つ以上、または同じタグと同じジャンル
- **限界:** 言葉が違えば、意味が近くてもつながりません。外部の AI は使いません。

## 収集（いいね）
- **X:** 未接続です。ログイン・Cookie・トークンは扱いません。
- **収集の規則（`public/js/core/collector.js`）。架空データの「いいね収集モック」でだけ試せます:**
  - 前回の試行開始から 6 時間あける
  - 同時に動くのは 1 つ（タブ間ロック＋10 分で切れる実行中の印）
  - 1 回 5 ページまで。続きの位置（cursor）を覚えて、次回そこから
  - 差分：取り込み済みのいいねに届いたら止める
  - 429：Retry-After と「6 時間 × 2^(連続回数−1)、上限 48 時間」の長い方まで待つ
  - 401・403・確認要求：その場で止まり、停止スイッチをオンにする
  - 停止スイッチはページごとに確かめる
  - 最後まで読めたときだけ「最後の成功」を更新し、途中で終わったら取得範囲と理由を残す

## 公開記事の読み込み（`server/`）
- **きっかけ:** あなたが「記事を読み込む」「画像を読み込む」を押したときだけ動きます。ブラウザはローカル API にしか話しかけません（CSP `connect-src 'self'`）。
- **宛先の検査:**
  - http(s)、ポート 80/443 のみ。資格情報入り URL と、秘密・追跡用クエリは送りません
  - 名前解決した全アドレスを検査し、非公開が 1 つでも混ざれば拒否します
  - IPv4 の非公開・予約範囲を拒否します
  - IANA IPv6 特殊用途レジストリで Globally Reachable=False のものを拒否します
  - IPv4 を埋め込む形式（射影・NAT64・6to4・Teredo）も方針として拒否します
  - localhost・.local・予約 TLD も拒否します
- **接続:**
  - 検査済みのアドレスに接続先を固定し、接続後の相手アドレスも検査し直します
  - 中継（プロキシ）経由の取得はしません。指定があれば失敗にし、サーバーは起動しません
- **転送:** 1 回ごとに検査し直し、最大 5 回までです。https から http への格下げは拒否します。
- **上限と種類:** 記事 3MB・画像 8MB（展開後も数える）、15 秒まで。記事は HTML / テキストだけ、画像は png・jpeg・gif・webp のみで、先頭のバイト列でも形式を確かめます。
- **送らないもの・残さないもの:** Cookie・認証ヘッダー・Referer は送らず、Set-Cookie は捨てます。
- **HTML の扱い:**
  - 文字だけを取り出し、script・iframe・svg などは中身ごと捨てます
  - 本文中の「指示」はただの文字として扱います
- **迂回しないもの:** ログイン・CAPTCHA・有料の壁は「読めなかった」として返します。
- **回数の制限:** 同時 2 件、1 分 30 回、同じサイトへは 2 秒あけます。
