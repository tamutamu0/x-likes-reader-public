# margin — あなたのいいねを読む個人用リーダー（第2段階・修正版）

> 以下は第2段階の配布時点の記録です。現在は公式 X API に接続済み。最新の起動条件・接続・検証結果は [../docs/STATUS.md](../docs/STATUS.md) と [../README.md](../README.md) を参照してください。

あなたが X でいいねした投稿を、手元で読む・整理するための個人用リーダーです。

- 読む流れ：未読 → 既読、あとで（日時つき）、残す・済み
- 整理：ジャンル分けと関連（すべてこの端末の中で計算）
- 記事：公開リンク先の記事を、明示操作で安全に読み込む

X の公式製品ではなく、X とは関係ありません。

## 起動

Node.js 18.17 以上が必要です。依存パッケージのインストールは不要です。

```
cd margin
node server.mjs
```

表示された http://127.0.0.1:47321 をブラウザで開いてください。

- **アドレス:** 127.0.0.1 だけで待ち受けます（新しいポート 47321）。`MARGIN_PORT=47400 node server.mjs` で変えられます。
- **保存先:** ブラウザの IndexedDB「margin-v1」です。この製品専用の新しい領域で、旧版の DB やファイルには触れません。ポートを変えると保存先も別になります。
- **初回:** 起動直後は空です。架空サンプルは「架空サンプルで試す」を押したときだけ入ります。

## テスト

```
node --test tests/*.test.mjs
```

Node 組み込みのテストで、76 件あります。この ZIP を作る直前に実行し、76 件すべて合格しました（`verification/node-test.log`）。

ブラウザでの検証スクリプト `tests/e2e/e2e.py` は Playwright を使う検証用で、Mac での確認には不要です。最後まで実行し、57 件すべて合格しました（`verification/e2e-result.json`）。画面は `verification/screenshots` にあります。

## 接続と承認の状態

- **X のいいねの自動取得：未接続。**
  - ログイン・Cookie・トークンは扱わず、保存もしません。
  - 収集の規則は、架空データの「いいね収集モック」でだけ試せます。
- **JSON ファイルの選択・読み込み・解析・保存（バックアップの書き出しを含む）：Mac での承認待ち。**
  - ボタンは押せません。貼り付けなどの別の入口もありません（`public/js/approvals.js` が `false`）。
- **公開記事の読み込み：あなたが「記事を読み込む」を押したときだけ動きます。**
  - ローカルサーバーが公開 http(s) URL を 1 件ずつ取りに行きます。
  - 内部・非公開の宛先や、転送先・DNS の細工は拒否します。中継（プロキシ）経由の取得はしません。
  - 大きさと時間に上限があります。HTML は実行しません。
  - ログイン・CAPTCHA・有料の壁は迂回しません。

## フォルダ

