# 状況（2026-10-11 12:5x 時点・修正版）

## この版で直したこと
1. **IPv6 の判定を IANA IPv6 特殊用途レジストリに合わせました**（`server/netguard.mjs`）。
   - 2001:2::/48（ベンチマーク）と 3fff::/20（文書用）を拒否するようにしました。
   - 同じ漏れとして、5f00::/16（SRv6）と 100:0:0:1::/64（ダミー）も拒否するようにしました。
   - 2001::/23 は原則拒否です。表で Globally Reachable=True の細かい割り当ては通します。
     - 2001:1::1〜3、2001:3::/32、2001:4:112::/48、2001:20::/28、2001:30::/28
   - IPv4 を埋め込む形式（射影・NAT64・6to4・Teredo）は、方針として拒否を続けます（理由は `docs/DESIGN.md`）。
   - 回帰テストを追加しました（`tests/netguard.test.mjs`）。
2. **中継（プロキシ）経由の取得を製品から取り除きました。**
   - `server/fetcher.mjs` から CONNECT と TLS 張り替えの経路を削除しました。
   - 中継の指定（upstreamProxy / proxy / agent）があれば、取りに行かずに失敗として返します。
   - `MARGIN_UPSTREAM_PROXY`・`MARGIN_UPSTREAM_CA`・`NODE_USE_ENV_PROXY` が設定されていると、サーバーは起動しません（fail-closed）。
   - 接続後に相手アドレスを検査し直す処理も残しているので、何かの理由で中継を通った場合も 127.0.0.1 宛てとして拒否されます。
   - テストを追加しました（fetcher・server・static）。
3. **取り込み画面のモックの実行記録が見えなかった問題を直しました。** 閉じた「決めてある規則」の外へ出しています。
4. **モックの 429・取得エラーの状況を直しました。** 差分で 1 ページ目に終わらないよう 1 ページ 1 件にし、2 ページ目で必ず起きるようにしています。
